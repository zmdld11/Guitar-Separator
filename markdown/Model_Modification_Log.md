# 吉他分离模型 (Separation Model) 迭代调整日志

为了防止后续开发重复踩坑、绕弯路，特此建立本日志文件，完整记录我们在探索、排错和提升“音轨分离模型”过程中尝试过的每一个方法及其效果。

---

## 📅 版本 1.0：初代基于双流混合的时域+频域网络 (原始 HTDemucs)
- **采用架构**：完整复现了经典的 HTDemucs 双分支结构（包含时域编码器与频域编码器）。包含大规模的通道数和 Transformer 层。
- **参数规模**：约 **52.7M**。
- **遇到问题**：
  1. 显存爆炸、训练速度极慢。
  2. 完全无法收敛。
- **最佳结果**：经过几轮 Epoch 测试，`Val SDR` 卡在 **-20 dB 到 -12 dB** 的糟糕数值。
- **根本原因**：庞大的参数量在目前较小的数据集下产生了严重的过拟合；同时，时域和频域的双流输出在融合成最终波形时，由于学习不到位，产生了严重的**相位抵消（Phase Cancellation）**，导致分离后的波形跟原波形发生破坏性干涉，产生了极低的 SDR。
- **结论**：放弃，当前数据集规模不足以驾驭双流波形重建架构。

---

## 📅 版本 1.1：轻量化 HTDemucs 与 Remixing 数据增强
- **采用架构**：在初代基础上砍掉了通道数（`channels` 64 -> 24）和 Transformer 维度（512 -> 256），精简后参数量下降至约 `3.7M`。
- **增补策略**：引入了在 Batch 维度的 `Remixing` (批次洗牌混合) 和 `MixUp` 数据增强，试图逼迫模型学习乐器本质特征而不是背答案。
- **遇到问题**：
  1. 不再显存溢出，批次也可以顺利进行。
- **最佳结果**：SDR 依然卡在 **-15 dB 附近** 毫无改善。
- **结论**：问题不出在数据增强和模型大小上，还是出在“模型如何处理时域重构（特别是相位复原）”的**核心数学原理**不符合当前场景。

---

## 📅 版本 2.0：推翻重写 - 纯频域 2D U-Net & 借用原曲相位 (Phase-aware Masking)
- **采用架构**：彻底删除所有时域分支流和Transformer层，重构为完全标准的 2D U-Net 网络。
- **核心逻辑**：将混合波形转换为 STFT **纯幅度谱 (Magnitude)**。使用 U-Net 预测一个 `0~1` 之间的软遮罩 (Sigmoid Mask)，用它在幅度谱上进行按比例削弱。重构波形时，**直接借用原曲的真实带噪相位 (Phase)**。
- **参数规模**：约 **1.97M** (非常轻量且稳定)。
- **遇到问题**：
  1. 发现史诗级 Bug 🐛：之前的 `Loss` 函数不仅在算幅度，竟然还在算**重构后的时域波形相差**以及**复数实虚部的相差**。因为模型输出用的永远是“充满杂音的原音频相位”，导致它在对比“拥有绝对干净纯相位的参考答案”时，Loss 会狠狠惩罚模型！模型为了修补那一点点无法改变的相位，就会把幅度谱改得面目全非，陷入无限循环死局。
- **最佳结果**：17 个 Epoch 后突破极限，达到 **最佳 SDR: -4.91 dB**。
- **结论**：方向是对的，属于“相位梯度受冤入狱”。

---

## 📅 版本 2.1：破局之战 - 彻底分离相位的纯幅度对数约束损失
- **调整内容**：
  1. **移除时域 L1 损失**：再也不直接对比波形。
  2. **引入全新 STFT Loss**：只对比 `target_mag` (目标纯幅度) 和 `est_mag` (预测纯幅度)。不再调用 `.real` 与 `.imag` 差异。
  3. **细化 Loss 组件**：加入了 `Spectral Convergence Loss`（关注全局能量框架）和 `Log Magnitude L1 Loss`。
  4. **输入端工程**：给喂进 U-Net 的幅度谱加上了 `torch.log1p(mag)`非线性压缩。
- **取得效果**：前 4 个 Epoch 就迅速追平了上一版的最好成绩，稳定向上。
- **最佳结果**：约 4~5 个 Epoch 达到 **最佳 SDR: -5.16 dB**（并呈现高速上升趋势）。
- **结论**：彻底走通了底层训练逻辑。

---

## 📅 版本 2.2：引入时空注意力与时间膨胀（Context-Aware U-Net）
- **核心痛点**：2.1 版本的纯卷积 U-Net 虽然能学，但是对音频时频图并不是平等的存在。纯 2D Conv 把它们当成普通图片处理，会导致“吉他扫弦和鼓声的宽频冲击”混在一起分不开。
- **架构升级**：
  1. 把基础的 `ReLU` 改为了对语音信号更友好的 `LeakyReLU(0.2)`。
  2. 融入 **SE Block (通道注意力机制)**：寻找最像吉他的频段通道。
  3. 引入 **Temporal Bottleneck (时序膨胀卷积)**：在 U-Net 感受野最深的池化瓶颈处，加入沿着时间轴横滑的 `Dilated Convolutions`，极大拉长了模型获取“前后音符联系”的时间视野。
- **最佳结果**：短时间测试 **约 -4 dB** 左右起步，听感有分离度但依旧不够清澈。

---

## 📅 版本 3.0：复数感知的相位修正架构 (Phase-Correction U-Net)
- **核心痛点**：此前的 2.x 版本有一个**致命的数学先天残疾** —— 所有的幅度都是被精准遮罩了，但是返回为波形时用的依然是**未经任何修改的 Mixed 混合相位**。如果分离出的吉他信号使用了带有鼓声和Bass残留的相位扭曲，必定会影响听感。
- **颠覆性重构**：
  1. 将输入由单通道 `Magnitude` 改为双通道: `[Log Magnitude, Normalized Phase]`。
  2. 赋予网络**同时修改相位的权力**。输出通道：`Mag Mask (Sigmoid)` 用来算幅度掩码；`Phase Delta (Tanh * Pi)`用来修正相位角度。
  3. 使用 `est_phase = original_phase + phase_delta` 的方式重新组装极坐标！
- **最佳结果**：在第 90 轮左右达到 **最佳 SDR: -4.99 dB 到 -4.60 dB** 左右，模型初期收敛极快，但打到这里时遇到了天花板，后期丧失动能（后劲不足）。

---

## 📅 版本 4.0：加入全局视野 (Frequency-Shared BiLSTM) [🔥最新运行]
- **核心痛点**：3.0 虽然解决了微观相位修补问题，但它依然基于 2D 卷积。卷积核在“横向时间流”上的视野是极其局限的（哪怕用了之前的膨胀卷积）。一首音频里的吉他长延音或者一段和弦扫弦，仅靠几帧几十帧的感知很难推断全局结构，这就导致模型学到最后卡在了“只能分局部”的瓶颈上。
- **架构升级**：
  在 U-Net 提取的最高阶层特征（Bottom 隐藏层）中，我引入了 `FrequencySharedBiLSTM` (基于频带共享的双向 LSTM 网络)：
  * **无限长视野**：LSTM 能保存并记忆几百帧甚至几千帧之前的波形信息（比如前面的吉他和弦记忆可以用来指导后方分离）。
  * **频带共享**：传统的 LSTM 处理高维频谱会导致极度消耗内存。而这里通过把 "Batch" 和 "频率通道" 合并，仅让 LSTM 在 "Time" 时间流上扫过。保证**只需微小的参数量，就能获得无限的上下文视野**。
- **当前状态**：已经接管后台进行重训验证，正在试图一举冲破 -4dB 的魔咒。
